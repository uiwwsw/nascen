# Nascen · Experiment 007

첫 한국어 실험은 문장 단위 예측에 원리의 조건·귀결·설명을 추가하면 적은 사례로도 새로운 상황에 대응할 수 있는지 살핍니다. Meta LCM은 SONAR 공간에서 다음 문장의 벡터를 예측했습니다. 이 실험에서는 고정된 다국어 E5와 작은 GRU를 사용해 주어진 후보 중 문맥에 이어질 문장을 고릅니다. [LCM 논문](https://arxiv.org/abs/2412.08821) · [다국어 E5 기술 보고서](https://arxiv.org/abs/2402.05672)

## 실험 설계

- 학습 사례 32개는 힘과 저항, 걸쇠를 푼 뒤 당기기, 물건 주인의 허락, 사용 범위를 다룹니다. 원리별 상황을 1·2·3·4개씩 사용해 총 8·16·24·32개 사례에서 학습합니다.
- 시험 28문항은 학습에 없던 상황 14개를 통째로 보류해 구성합니다. 동일 의미의 표현 변형, 부정과 예외, 새로운 대상에 대한 원리 전이, 두 원리의 조합을 평가합니다. 물체 조합 문항의 선택지에는 두 원리가 만들 수 있는 결과 네 가지를 모두 넣었습니다.
- A는 고정된 한국어 글자·단어 n-gram을 입력으로 씁니다. B와 C는 고정한 다국어 E5로 문장을 벡터화합니다. A·B·C는 같은 GRU와 문장 예측 목표를 사용하고, 검토를 통과한 관계 쌍을 함께 학습합니다. C에는 같은 가중치에 추가로 원리 설명과의 정렬, 예외를 포함한 조건에서 결과를 예측하는 손실을 적용합니다.
- D는 사람이 학습 자료에서 만든 문자열 조건으로 직접 규칙을 실행합니다. 규칙이 고른 결론과 보기의 E5 벡터를 비교하고, 조건을 찾지 못하거나 최고 점수가 동률이면 유보합니다. 유보는 오답으로 집계합니다.
- A·B·C는 같은 초기화 시드 세 개로 각각 학습합니다. 학생은 한국어 문맥과 순서가 섞인 후보 문장만 받아 점수를 매깁니다. 정답은 오프라인 집계에서만 사용합니다.
- 교사는 학습용 관계 쌍을 분류하고 사람이 명시한 기준 원리를 한국어 조건·귀결·설명으로 정제합니다. 관계 쌍은 독립 기준과 대조하고 원리 설명은 별도 검토 파일을 남깁니다. [교사 수업](experiment-007-lessons.json) · [원리 검토](experiment-007-review.json)

## 결과

시드 11·22·42의 평균입니다. 균등 무작위 선택의 기대 정확도는 46.4%입니다.

| 학습 사례 | A · 표면 토큰 | B · 문장 의미 | C · 문장 의미와 원리 |
| ---: | ---: | ---: | ---: |
| 8 | 48.8% | 35.7% | 39.3% |
| 16 | 52.4% | 31.0% | 44.0% |
| 24 | 53.6% | 47.6% | 47.6% |
| 32 | 60.7% | 57.1% | 47.6% |

D는 28문항 중 7문항에 답해 5문항을 맞혔습니다. 전체 정확도는 17.9%이고 문항 응답률은 25.0%입니다. 낱말 조건이 새로운 표현에 대응하지 못하면서 유보가 많았습니다.

32개 사례를 사용한 조건에서 B와 C의 표현 변형 정확도는 모두 75.0%였습니다. 예외가 달라지는 두 문항을 모두 맞힌 비율은 B 25.0%, C 8.3%였습니다. 새로운 대상에 대한 전이 정확도는 B 70.8%, C 45.8%였고, 원리 조합은 B 33.3%, C 29.2%였습니다. C는 잠금 해제와 이동을 함께 판단하는 `stage-cover-0`을 세 시드 모두 틀렸고, 네 보기로 제시한 물체 조합에서는 전체 12개 응답 중 1개를 맞혔습니다. [문항별 결과와 오답](experiment-007.json)

같은 사례 수에서 C는 8개와 16개 구간에서 B보다 높았고, 네 구간 모두에서 A보다 낮았습니다. 학습 입력 크기가 비슷한 C 24개(9,329바이트)와 B 32개(9,359바이트)의 정확도는 47.6%와 57.1%였습니다. 한 번의 상황 분할과 28개 문항에서 원리 추가의 일관된 개선이나 데이터 효율 우위는 확인되지 않았습니다. 다음 비교에서는 인코더가 부정과 조건 변화를 얼마나 구별하는지, 원리 학습 손실이 판단을 얼마나 바꾸는지 각각 측정할 필요가 있습니다.

## 비용과 교사 검토

- 최종 Qwen 수집에서 관계 라벨 14개 중 독립 기준과 불일치한 3개(21.4%)를 제외했습니다. 원리 4개는 조건·결과를 별도로 검토해 사용했습니다. [리뷰](experiment-007-review.json)
- A와 B에 공통으로 필요한 교사 요청은 2회, 입출력 합계 1,223토큰, 경과 11.0초였습니다. C는 관계와 원리를 합쳐 6회, 3,001토큰, 34.3초였습니다. D에 필요한 원리 요청은 4회, 1,778토큰, 23.3초였습니다. 최종 수집 전 프롬프트 탐색에서 확인 가능한 비용은 별도로 14,468토큰과 201.8초 이상입니다. 일부 거절된 응답은 비용 기록이 남지 않았습니다.
- 32개 사례에서 학생 훈련의 평균 CPU 시간은 B 0.10초, C 0.18초였습니다. 모델 로드와 문장 벡터 계산 시간은 JSON에 따로 기록했습니다. B·C·D가 공유한 고정 E5에는 약 1억 1,765만 개의 매개변수가 있습니다. E5가 처리한 토큰 수와 사전학습 비용은 이번 실험의 측정 범위 밖이므로, 전체 토큰이나 비용의 절감 여부는 아직 판단할 수 없습니다. [실행 환경과 비용](experiment-007.json)

## 재현

Python 3.12~3.14와 CPU를 사용합니다. 다음 실행은 저장된 수업, 검토 결과, 로컬 E5 파일을 읽습니다. 보고된 학습과 독립 추론은 Qwen 서버를 종료한 뒤 실행했습니다. [다국어 E5 모델 카드](https://huggingface.co/intfloat/multilingual-e5-small)

```sh
python -m pip install -r requirements.txt -r requirements-teacher.txt
hf download intfloat/multilingual-e5-small \
  config.json model.safetensors tokenizer.json tokenizer_config.json \
  special_tokens_map.json sentencepiece.bpe.model \
  --revision fd1525a9fd15316a2d503bf26ab031a61d056e98 \
  --local-dir .nascen/teacher-assets/multilingual-e5-small

python -m nascen.semantic_experiment \
  --lessons docs/experiment-007-lessons.json \
  --review docs/experiment-007-review.json \
  --encoder .nascen/teacher-assets/multilingual-e5-small \
  --output .nascen/experiment-007.json \
  --checkpoint .nascen/experiment-007-student.pt
```

가장 많은 학습 사례를 사용한 C의 첫 번째 시드 모델을 저장합니다. 같은 인코더와 체크포인트로 새 상황에 대한 후보를 평가할 수 있습니다. 출력의 `choice`는 0부터 시작하는 보기 번호입니다. 아래 실행에서 모델은 1번을 골랐으며, 정답은 0번입니다.

```sh
python -m nascen.semantic_reasoning \
  --checkpoint .nascen/experiment-007-student.pt \
  --encoder .nascen/teacher-assets/multilingual-e5-small \
  --context '도서관에 잠금쇠를 풀어 둔 서류함이 있다.' '사서가 손잡이를 당겼다.' \
  --options '서류함이 열렸다.' '서류함은 닫힌 상태로 남았다.'
```

교사 수업을 다시 수집할 때는 아래와 같이 실행합니다. 기록된 수집에는 llama.cpp b12556과 Qwen3-4B-Q4_K_M을 사용했으며, 가중치 SHA-256은 교사 수업 파일에 들어 있습니다.

```sh

# 다른 터미널에서 실행

```

새 수업에는 새 검토가 필요합니다. 검토 파일에는 수업 JSON의 `nascen.semantic_dataset.digest` 값인 `lessons_sha256`, 원리 키별 `accepted`와 `reason`을 담은 `principles`가 들어갑니다.

## 잠재 전이 엔진

문장의 의미를 예측하던 초기 비교에 이어, **상태와 행동이 주어졌을 때 어떤 변화가 일어나는지**를 학습하는 엔진을 구현했습니다. NEO는 관찰로부터 실행 가능한 잠재 프로그램을 유도합니다. 여기서는 한국어 경험에 필요한 작은 전이 모델로 범위를 잡고, 학습 가능한 슬롯이 서로 다른 변화에 쓰이는지 측정합니다. [LCM 논문](https://arxiv.org/abs/2412.08821) · [NEO 논문](https://arxiv.org/abs/2605.03413)

### 상태 예측과 학습 신호

- 고정한 다국어 E5가 문장당 384차원 벡터를 만들고, 학생은 상태와 행동을 128차원으로 투영합니다. 공식 SONAR는 한국어를 지원하며 1,024차원 벡터와 Fairseq2 환경을 사용합니다. 이번 CPU 실험에는 로컬에 검증된 E5를 사용했습니다. [SONAR 공식 구현](https://github.com/facebookresearch/SONAR) · [다국어 E5](https://arxiv.org/abs/2402.05672)
- 상태와 행동을 바탕으로 8개 학습 슬롯의 가중치를 정하고, 슬롯의 혼합으로 다음 상태를 예측합니다. 슬롯에 미리 부여한 원리 이름은 없습니다. 행동이 이어지면 모델이 예측한 잠재 상태를 다음 단계에 전달하고, 각 단계의 후보는 순위를 매길 때만 사용합니다.
- 전체 목적함수는 다음 상태 벡터 예측, 오답 후보와의 대조, 변화 벡터와 교사 원리의 정렬, 표현을 바꾼 입력 사이의 일관성을 합칩니다. 기본 가중치는 각각 1, 1, 0.3, 0.2입니다. `--w-next`, `--w-contrast`, `--w-principle`, `--w-consistency`로 조정합니다.
- 트랙에서는 이동, 장애물, 목표선 도착을 다룹니다. 모의 자원 이용 훈련에서는 소유자 승인, 현재 비상상황, 사용 범위를 다룹니다. 100·300·1,000개 경험은 같은 학습 풀의 중첩된 부분집합입니다. 학습 풀은 77개 상태·행동 구조를 여러 대상과 표현으로 렌더링합니다.
- 시험에는 학습과 다른 물체의 이름, 학습에서 제외한 상태·행동 조합, 처음 보는 연속 행동을 사용합니다. 표현 변형, 부정, 주어, 시점과 조건을 바꾼 문항도 분리했습니다. 전체 90문항 중 두 문항은 외부 세계 지식이 필요한 탐색용으로 별도 표시했습니다. 14개 연속 행동 문항은 중간 상태와 마지막 상태를 각각 채점합니다.
- A·B·C는 각 예산에서 같은 E5, 같은 282,760개 매개변수 구조, 같은 경험, 시드 11·22·42, 동일한 240회 갱신을 사용합니다. D는 교사의 검토된 원리에서 사람이 작성한 전이 프로그램을 E5로 검색해 실행합니다. 학생은 한국어 초기 상태, 행동, 후보 결과만 입력받습니다. 학습 규칙과 시험 정답은 생성 및 채점 단계에만 사용합니다.

### 결과

외부 지식 문항을 제외한 88문항의 최종 상태 정확도입니다. 신경망은 세 시드 평균을 표시합니다.

| 학습 경험 | A · 의미 전이 | B · 원리 추가 | C · 원리 설명 셔플 |
| ---: | ---: | ---: | ---: |
| 100 | 39.4% | 38.3% | 39.8% |
| 300 | 36.7% | 38.3% | 36.7% |
| 1,000 | 41.3% | 40.2% | 39.8% |

D는 **45.5%**였습니다. 행동을 무시하고 이전 상태와 가장 가까운 후보를 고르는 E5 기준선은 **53.4%**였습니다. 학습 경험 300개에서 교사 설명의 25%를 고의로 틀린 설명으로 바꾼 조건은 37.9%였습니다. 300개 조건에서 관찰한 B의 이점은 다른 데이터 규모에서 이어지지 않았습니다. [시드별 결과 및 예측](experiment-007-theory.json)

### 실패 분석

- **데이터.** 학습에는 단일 전이를 사용하고 여러 행동이 이어지는 상황은 평가에 남겨 뒀습니다. 상태가 유지되는 문항에서는 이전 상태를 복사하는 기준선에 이점이 있었습니다. 학습 사례 수에는 동일 구조를 다른 대상으로 표현한 사례가 포함됩니다.
- **의미 표현.** E5에서 정답이 달라지는 부정 쌍의 결과 문장 코사인 유사도는 평균 0.993, 주어가 달라지는 쌍은 0.999였습니다. 표현만 달라진 쌍의 정답 문장 평균은 0.930이었습니다. 이 데이터의 문장 벡터만으로는 표현 변경과 결과 변경을 유사도 순서에서 일관되게 가르기 어려웠습니다.
- **원리 학습.** 1,000개 조건의 B에서 세 시드 모두 시험의 모든 단계에 같은 슬롯을 최고 가중치로 선택했습니다. 시드별 1위 슬롯에 평균 99.9% 이상의 질량이 실렸습니다. 원리 문장을 정렬 손실에 사용했어도 서로 다른 전이를 담당하는 슬롯 분화는 관찰되지 않았습니다.
- **여러 단계 추론.** 1,000개 조건의 B는 중간 상태 30.0%, 최종 상태 26.2%, 전 단계 동시 정답률 14.3%를 기록했습니다. 부정·주어·시점·조건을 바꾼 쌍에서는 두 답을 모두 맞힌 비율이 0%였습니다. 오류 목록에는 조건을 바꿔도 판단이 유지되는 예와 중간 상태에서 틀린 뒤 마지막 답도 어긋난 예가 포함되어 있습니다. [문항별 예측과 오답](experiment-007-theory.json)

Qwen의 첫 수집에서는 여섯 원리 모두 적용 조건이나 예외의 오류·누락이 있었습니다. 조건과 예외를 명시한 학습 기준을 바탕으로 다시 수집하고, 원리 여섯 개를 검토해 사용했습니다. 이는 교사의 설명 정제 비용이며 독립적인 자연 법칙 발견을 측정한 결과로 볼 수는 없습니다. 첫 수집은 6회, 3,392토큰, 60.2초였고 최종 수집은 6회, 3,953토큰, 68.2초였습니다. 1,000개 학습 경험에서 중복 문장을 제외한 E5 입력은 789문장, 29,215토큰이었습니다. 원리와 잘못된 원리 대조군용 설명에 951토큰을 추가로 처리했고, 시험 문장에는 6,998토큰이 들었습니다. Qwen 호출과 E5 비용은 학생의 훈련 시간과 별도로 기록했습니다. E5의 사전학습 비용이 포함된 종단 간 토큰 또는 비용 절감은 이 비교에서 확인할 수 없습니다. [비용과 실행 환경](experiment-007-theory.json)

### 전이 엔진 재현

앞 절의 E5 설치 명령 또는 같은 로컬 스냅샷을 사용합니다. 저장된 교사 수업을 쓰므로 다음 명령에는 Qwen 서버가 필요하지 않습니다. `prepare`는 `train.json`, `exam.json`, `answers.json`과 각 파일의 해시를 남깁니다. `--with-theory`는 검토한 원리와 적용 조건을 학습 파일에도 포함합니다.

```sh
python -m nascen.theory_language prepare --with-theory
python -m nascen.theory_language train --mode semantic --budget 100
python -m nascen.theory_language train --mode principle --budget 100
python -m nascen.theory_language evaluate
python -m nascen.theory_language benchmark \
  --output .nascen/theory-language/results.json \
  --checkpoint-dir .nascen/theory-language/checkpoints
```

저장한 학생에 새 한국어 입력을 직접 줄 수도 있습니다. 연속 행동은 `--action`과 해당 결과 후보 `--option` 묶음을 순서대로 반복합니다.

```sh
python -m nascen.theory_language predict \
  --checkpoint .nascen/theory-language/checkpoints/principle-1000-11.pt \
  --before '훈련용 지도는 주인의 승인과 사용 이력이 없고 현재 비상상황도 없다.' \
  --action '지도의 소유자가 사용을 승인했다.' \
  --option '소유자 승인이 생겼다.' '소유자 승인이 없다.'
```

이 입력에서 1,000개 경험으로 학습한 시드 11의 학생은 기존 상태인 ‘소유자 승인이 없다’를 골랐습니다. 모의 훈련의 기준 결과는 ‘소유자 승인이 생겼다’입니다.

수업을 새로 모으려면 앞 절의 루프백 Qwen 서버를 실행한 다음 `python -m nascen.theory_language collect --teacher MODEL_ID --output .nascen/theory-language/new-lessons.json`을 사용합니다. 새 수업을 사용하기 전에는 기준 조건·결과·예외와 대조해 검토하고, 수업 파일의 해시를 새 검토 파일에 기록합니다.
