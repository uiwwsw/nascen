# Experiment 008 · 보기 누출을 없앤 상태 전이 시험

Experiment 007의 전이 시험에서 학생은 상태를 복사하는 기준선을 넘지 못했고, 여러 행동이 같은 잠재 슬롯으로 보내졌습니다. 이번에는 시험의 보기 구성, 결과 벡터, 슬롯 선택을 각각 점검했습니다. [이전 전이 실험](experiment-007.md#잠재-전이-엔진)

## 시험부터 교정

기존 시험은 정답 상태에 세 조건 중 하나씩만 바꾼 오답을 붙였습니다. 그러면 정답은 다른 모든 보기와 한 조건씩만 다르고, 오답은 서로 두 조건에서 달라집니다. 따라서 상태와 행동을 가리고도 보기의 구조만으로 모의 환경의 108단계를 모두 맞힐 수 있었습니다. 실제 한국어 보기만 E5로 비교해 나머지 보기에 평균적으로 가장 가까운 문장을 골랐을 때도 **107/108**을 맞혔습니다. 이 점수는 기존 학생의 내부 동작을 보여주는 수치가 아니라 시험에 답 단서가 있었다는 진단입니다.

새 시험은 세 조건의 가능한 조합 **8개를 결과와 독립적으로 모두** 제시합니다. 같은 상황에서 행동만 바꾼 문항 쌍은 보기 집합을 공유하며 정답이 달라집니다. 새 물체와 원래의 학습 제외 상태·행동 조합을 사용했고, 외부 지식 두 문항은 전체 정확도에서 제외했습니다. 전체 정확도와 함께 실제 변화가 있었던 단계, 유지 단계, 반사실 쌍의 두 답을 모두 맞힌 비율, 연속 행동의 전 단계 정답률을 기록했습니다.

## 모델 비교

A는 기존 학생과 같은 구조로 새 보기 구성에서 다시 학습했습니다. B는 훈련 벡터를 중심화·표준화하고, 상태와 후보를 공유 투영층에 넣어 결과 공간을 학습합니다. C는 슬롯 점수의 범위를 제한하고, 개별 선택은 뚜렷하게 하되 전체에서는 여러 슬롯을 쓰도록 손실을 추가합니다. D는 B와 C를 결합하고 E는 여기에 검토된 교사의 원리 설명을 더합니다. A~E는 각 데이터 예산에서 같은 경험, 초기화 시드, 학습 횟수와 학생 용량으로 비교했습니다.

첫 비교에서 B는 변화한 상태를 더 잘 맞혔지만, 상태가 유지되는 단계에서 성능이 떨어졌습니다. 두 번째 시험에서는 같은 상태를 그대로 유지할지 학습하는 보조 신호를 B에 더해 F를 만들었습니다. 신호는 학습 사례의 관측 전후 문장이 달라졌는지로 만들고, 추론 시 학생이 직접 변화 가능성을 계산합니다. 상태가 유지될 때의 점수와 전이 후 상태의 점수를 학습한 변화 가능성으로 합칩니다. 두 번째 시험은 별도 물체 목록과 새로운 연속 행동 순서를 사용했습니다. A·B·F를 세 시드에서 다시 학습했으며, F는 변화 예측층의 매개변수가 추가됩니다.

## 결과

진단 시험에서 보기에만 의존한 기준선은 최종 상태 정확도 **13.6%**였습니다. 8개 보기의 균등 선택 기대값은 12.5%입니다. 경험 1,000개에서 결과 표현을 다시 학습한 B는 실제 변화가 있는 단계 정확도를 A의 5.7%에서 20.8%로 높였습니다. 같은 조건에서 상태 유지 단계 정확도는 73.3%에서 48.5%로 떨어졌습니다. 슬롯 사용만 조정한 C에서는 엔트로피로 환산한 유효 슬롯 수가 1.00에서 3.76으로 늘었고, 반사실 쌍에서 두 답을 모두 맞힌 비율은 여전히 0%였습니다. 1,000개 조건 D의 전체 정확도는 34.5%, 원리를 더한 E는 34.1%였습니다. ### 별도 확인 시험

| 학습 경험 | A · 기존 모델 | B · 결과 표현 학습 | F · 결과 표현과 변화 여부 학습 |
| ---: | ---: | ---: | ---: |
| 100 | 41.7% | 36.0% | 51.1% |
| 300 | 43.9% | 45.5% | 57.6% |
| 1,000 | 47.0% | 43.9% | 58.7% |

이 시험에서 보기만 이용한 기준선은 **12.5%**, 모든 단계에서 시작 상태를 고르는 기준선은 **55.7%**였습니다. 경험 300개와 1,000개의 F는 세 시드 모두에서 시작 상태 기준선을 넘었습니다. 경험 1,000개의 F는 상태가 바뀐 단계에서 **20.9%**, 유지된 단계에서 **83.6%**를 기록했습니다. B의 변화 단계 정확도는 26.8%로 더 높았으나, 유지 단계 정확도는 50.3%였습니다. [확인 시험 결과 JSON](experiment-008-confirmation.json)

연속 행동의 모든 단계를 동시에 맞힌 비율은 1,000개 경험으로 학습한 F에서 **9.5%**, 시작 상태 기준선에서 **14.3%**였습니다. 다음에는 F의 상태 유지 학습을 고정하고, 같은 수의 관찰 전이를 한 단계씩 보여 주는 조건과 여러 단계로 이어 보여 주는 조건을 비교합니다. 처음 보는 행동 순서에서 전 단계 정답률을 주 지표로 삼고, 비교용으로 매 단계에서 실제 이전 상태를 제공해 한 단계 예측 오류와 누적 오류를 구분할 수 있습니다.
