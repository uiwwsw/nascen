# Experiment 009 · 행동의 효과와 중간 상태

같은 관찰을 여러 단계로 연결해 학습하면, 처음 보는 행동 순서에서 중간 상태를 더 정확히 이어갈 수 있을까? Experiment 008에서 사용한 변화 여부 예측 모델을 바탕으로, 한 단계 학습과 3단계 학습을 비교했습니다. 중간 상태에 관측 결과를 반영하는 손실도 별도로 시험했습니다. NEO는 자체 환경에서 중간 상태를 인코딩 가능한 표현에 맞추는 학습의 효과를 비교했습니다. 이번 실험은 그 질문을 한국어로 표현한 모의 환경에 적용합니다. [Experiment 008](experiment-008.md) · [NEO 논문](https://arxiv.org/html/2605.03413v4)

## 시험 범위

- 두 모의 환경에서 길이 3인 학습 구간 300개를 사용했습니다. 총 900개 관측 전이가 들어 있고 원문 기준으로 중복을 빼면 736개입니다. 네 조건은 같은 인코더, 모델, 초기화 시드, 관측 전이, 배치 표본을 사용했습니다. 480회 갱신의 각 단계에서 네 조건은 같은 48개 전이를 골라 손실을 계산했습니다.
- 한 단계 학습은 각 단계의 실제 시작 상태에서 예측합니다. 3단계 학습은 첫 상태와 행동 세 개를 받아 자기 예측을 다음 단계로 넘깁니다. 두 조건 모두 각 단계의 관측 결과로 채점합니다. 관측 정렬 조건에는 예측 상태와 실제 결과 문장을 투영한 벡터의 거리를 줄이는 항을 추가했습니다.
- 평가의 한 단계 행동 쌍은 같은 초기 상태에서 행동만 바꿉니다. 순서 쌍은 같은 행동을 서로 다른 순서로 적용하며, 두 경우의 최종 상태가 다릅니다. 각 단계의 보기는 가능한 상태 8개를 모두 제시하며 짝을 이룬 문항과 표현을 바꾼 문항의 보기 순서를 고정했습니다.
- 시험에서 사용하는 25종의 개별 상태·행동 조합은 모두 학습 관찰에 들어 있습니다. 시험의 3단계 행동 순서는 학습에서 제외했습니다. 평가 대상의 물체 이름은 학습 대상과 겹치지 않습니다.
- 상태 문장과 행동 문장 각각에 익숙한 표현과 학습에 없던 표현을 사용했습니다. 같은 물체와 상황을 네 가지 표현 조합에서 반복했습니다. 전체 672문항은 **기본 상황 쌍 84개를 네 표현 조합으로 렌더링한 수**입니다. 한 단계 행동 레시피 6개와 순서 레시피 8개를 사용했으므로 독립적인 문제 종류는 제한적입니다.

## 결과

세 초기화 시드의 평균입니다. 행동 쌍 점수는 행동을 바꾼 두 문항을 모두 맞힌 비율입니다. 전 단계 점수는 세 행동의 상태를 모두 예측한 비율입니다.

| 학습 조건 | 한 단계 행동 쌍 | 3단계 전부 정답 | 순서를 바꾼 쌍의 양쪽에서 3단계 전부 정답 |
| --- | ---: | ---: | ---: |
| 한 단계 | 40.0% | 18.4% | 7.6% |
| 한 단계 + 관측 정렬 | 40.0% | 16.4% | 4.0% |
| 3단계 연결 | 19.9% | 7.6% | 0.7% |
| 3단계 연결 + 관측 정렬 | 26.4% | 11.2% | 3.8% |

보기만 비교하거나 시작 상태를 복사한 기준선은 한 단계 행동 쌍에서 모두 0%였습니다. 두 기준선의 3단계 전부 정답률도 0%였습니다. 이 설정에서 3단계 연결 학습은 세 시드 모두에서 한 단계 학습보다 전 단계 정답률이 낮았습니다. 연결 학습에 관측 정렬을 추가하자 평균은 올라갔지만, 개선은 세 시드 중 하나에서 나타났습니다. [시드별 수치와 오답 예시](experiment-009.json)

### 어디에서 차이가 생겼나

한 단계 학습 모델의 행동 쌍 성능을 같은 물체와 상황에서 비교했습니다.

| 상태 문장 | 행동 문장 | 두 행동의 결과 모두 정답 |
| --- | --- | ---: |
| 익숙한 표현 | 익숙한 표현 | 82.4% |
| 익숙한 표현 | 새 표현 | 41.7% |
| 새 표현 | 익숙한 표현 | 23.1% |
| 새 표현 | 새 표현 | 13.0% |

상태 표현을 바꾸면 시작 상태와 보기가 함께 바뀝니다. 이 결과는 해당 표현 조합에서의 취약성을 보여 줍니다. 시작 상태를 읽는 부분, 결과 후보를 읽는 부분, 둘을 잇는 모델 가운데 어느 부분이 영향을 얼마나 받았는지는 따로 측정해야 합니다.

한 단계 학습 모델에 시험의 실제 이전 상태를 매번 제공하면, 두 번째와 세 번째 단계 정확도가 **37.4%에서 57.2%**로 올랐습니다. 전 단계 정답률은 **18.4%에서 22.8%**로 올랐습니다. 실제 이전 상태는 오류가 쌓이는 구간을 확인하는 보조 진단에만 쓰였으며, 표의 주 평가에서는 모델이 스스로 상태를 이어갑니다.

## 결론과 다음 시험

이번 시험에서 확인한 것은 두 모의 환경에서 행동을 구분할 수 있는지와, 동일한 관찰을 3단계로 이어서 가르칠 때 성능이 어떻게 달라지는지입니다. 익숙한 표현에서는 두 행동의 효과를 구분하는 경우가 많았습니다. 표현을 바꾸거나 예측을 다음 단계에 전달하면 성능이 낮아졌습니다. 표현을 반복해 문항 수를 늘려도 실제 상황에서의 전이나 원리 발견을 검증하는 데 필요한 새로운 증거는 생기지 않습니다.

다음에는 **한 단계만 고정하고 표현의 영향을 더 세분화**할 수 있습니다. 동일한 상황에서 시작 상태 문장만 바꾸는 경우, 행동 문장만 바꾸는 경우, 결과 보기 문장만 바꾸는 경우를 따로 평가합니다. 아직 학습에 쓰지 않은 사람이 작성한 한국어 표현을 사용하면 어떤 문장 입력이 취약한지 더 잘 가릴 수 있습니다. 그 단계에서 표현을 넘어 행동의 효과를 구분하는 능력이 안정되면, 새로운 행동 순서나 다른 종류의 상태 변화로 시험 범위를 넓힐 근거가 생깁니다.
