# 관측 조건을 학습하는 Nascen 모델

Experiment 009에서 상태와 결과 보기의 표현을 바꾸면 판단이 크게 흔들렸습니다. 기존 모델은 문장 표현이 달라도 전이 결과가 같도록 학습했지만, 입력 상태와 결과 보기 안에서 같은 조건을 직접 대응시키는 학습은 없었습니다. 이 문제를 반영해 상태 읽기, 행동 읽기, 다음 상태 예측을 별도로 학습하는 모델을 추가했습니다. [Experiment 009](experiment-009.md)

## 모델과 학습

1. 고정 다국어 E5로 문장 전체와 문장 부호를 기준으로 나눈 절의 벡터를 만듭니다. 한국어 문구를 조건표와 대조하는 파서는 사용하지 않습니다.
2. 상태를 읽는 신경망은 절별로 이동·경로·도착 같은 관측 조건을 읽습니다. 같은 조건의 다른 표현에는 같은 학습 정답을 주고, 조건이 뒤집힌 표현에는 다른 정답을 줍니다. 행동 표현도 뜻이 같은 경우 같은 행동을 가리키게 학습합니다.
3. 전이 신경망은 관찰된 전후 상태와 행동으로 다음 상태를 학습합니다. 예측한 상태를 다시 입력으로 쓸 수 있도록, 관측 상태와 예측 상태가 같은 표현 공간을 사용합니다. 보기 문장은 그 공간에서 점수를 매길 때 사용합니다.

두 모의 환경에서 관측 가능한 상태 16가지와 행동 11종을 정의했습니다. 기존 비교군과 동일한 관측 전이 900개를 사용했고, 새 모델에는 학습용 상태 문장 1,740개, 행동 문장 66개, 조건 절 80개에 관측 정답을 붙였습니다. 따라서 성능 차이에는 새 모델 구조와 추가 지도 정보의 효과가 함께 포함됩니다. 상태의 관측 항목은 사람이 정했고, 행동에 따른 다음 상태는 신경망이 관측 자료로 학습했습니다.

## 검증

Experiment 009와 동일한 시험에 더해, 새로운 물체와 한국어 표현을 사용한 시험을 만들었습니다. 같은 상황에서 시작 상태 문장, 행동 문장, 보기 문장을 한 곳씩 또는 모두 바꿨습니다. 아래 수치는 시드 11·22·42의 평균입니다. 행동 쌍은 같은 시작 상태에서 행동이 다른 두 문항을 모두 맞힌 비율입니다. 연속 행동은 3단계의 상태를 모두 맞힌 비율입니다.

| 표현 조건 | 기존 행동 쌍 | 새 모델 행동 쌍 | 기존 연속 행동 | 새 모델 연속 행동 |
| --- | ---: | ---: | ---: | ---: |
| 기존 표현 | 75.9% | 100.0% | 48.6% | 100.0% |
| 시작 상태만 변경 | 24.1% | 89.8% | 18.8% | 98.3% |
| 행동만 변경 | 63.0% | 100.0% | 25.0% | 100.0% |
| 보기만 변경 | 9.3% | 100.0% | 9.4% | 100.0% |
| 모두 변경 | 1.9% | 89.8% | 1.7% | 98.3% |

학습 명령의 기본 시드 11에서는 모든 표현을 바꾼 조건에서 행동 쌍 **69.4%**, 연속 행동 **94.8%**였습니다. 다른 두 시드는 이 조건에서 두 지표 모두 100%였습니다. Experiment 009의 이전 표현 변형까지 합친 평가에서 전 단계 정답률은 **18.4%에서 70.8%**로 올랐습니다. 이 결과는 두 모의 환경과 정해진 관측 항목 안에서의 전이를 측정합니다. 자유로운 한국어 상황이나 새 종류의 원리를 발견하는 성능은 이 시험의 범위 밖입니다. [시드별 원본 결과](experiment-010.json)

## 사용

[기존 한국어 실험](experiment-007.md#재현)의 E5 스냅샷을 설치한 환경에서 실행합니다.

```sh
python -m nascen.theory_language train-robust
python -m nascen.theory_language evaluate-robust
```

학습한 모델은 `.nascen/theory-language/robust.pt`에 저장됩니다. 파일이 있으면 `predict`가 이 모델을 기본으로 사용합니다. `--checkpoint`로 이전 모델이나 다른 가중치 파일을 지정할 수 있습니다.

```sh
python -m nascen.theory_language predict \
  --before '회전축 모형은 제자리에 멈춰 있다. 앞으로 가는 길에는 가로막는 것이 없다. 지금까지 목표선을 통과한 기록은 없다.' \
  --action '담당자가 모형을 있는 힘껏 밀어 주었다.' \
  --option '모형은 멈춰 있다. 앞길은 열려 있다. 목표선에 이른 적이 없다.' '모형은 움직이는 중이다. 앞길은 열려 있다. 목표선에 이른 적이 없다.' \
  --action '조작을 더 하지 않고 한 단계 기다렸다.' \
  --option '모형은 정지해 있다. 앞길은 열려 있다. 목표선에 도착했다.' '모형은 계속 움직이고 있다. 앞길은 열려 있다. 목표선에 간 적이 없다.'
```

기본 시드로 저장하고 불러온 모델은 첫 행동 뒤에는 움직이고, 두 번째 행동 뒤에는 도착하고 멈추는 결과를 골랐습니다. 학습이나 추론 중에 교사 모델을 부를 필요는 없습니다.

동일한 학습 관찰로 기존 모델과 새 모델을 비교하는 명령입니다.

```sh
python -m nascen.theory_language.observation_benchmark --output .nascen/experiment-010.json
```
