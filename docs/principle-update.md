# 원리 갱신과 상태 전이

Nascen의 관측 모델은 한국어 문장에 나타난 상태와 행동을 읽습니다. 이번 변경으로 원리 학습 모델은 그 결과에 개입할 수 있고, 이후 관찰을 받아 원리의 가중치를 갱신할 때는 이전에 검증한 사례를 다시 확인합니다.

| 기존 동작 | 변경 | 확인 결과 |
| --- | --- | --- |
| 관찰을 추가할 때 기존 예측과 일치해도 가중치를 갱신했습니다. | 이미 맞히는 관찰은 검증 사례로 보관하고 가중치를 유지합니다. | 011의 원리 8개와 시드 3개에 같은 관찰 2개를 다시 제공했습니다. 정확도가 떨어진 실행이 12/24에서 0/24로 줄었습니다. 평균 균형 정확도는 수업 직후 100.0%, 기존 갱신 뒤 83.9%, 새 방식 적용 뒤 100.0%였습니다. |
| 관찰에서 고친 예측이 이전 판단을 망가뜨리는지 검사하지 않았습니다. | 기존 예측과 다른 관찰이 들어오면 별도 검증 사례를 확보한 뒤 수정안을 만듭니다. 새 관찰과 검증 사례를 모두 맞히는 수정안을 채택합니다. | 등불 모델의 모의 관찰에 의도적으로 다른 결과를 넣었습니다. 별도 사례를 보존한 제안은 채택했고, 별도 사례의 오답을 만든 제안은 거부하고 이전 가중치를 유지했습니다. |
| 010의 상태 전이와 011의 원리 예측은 따로 실행됐습니다. | 011의 학습 구조로 트랙 원리를 학습하고, 그 모델의 움직임 점수를 010의 한 단계 결과 점수에 반영합니다. | 010은 열린 경로에서 이미 도착한 물체와 미도착 물체 모두 움직인다고 예측했습니다. 도착 예외가 있는 변형 규칙을 적용하자 도착한 물체의 예측만 정지로 바뀌었습니다. |

011 재실행은 이미 맞히던 관찰 때문에 발생한 성능 저하를 막는지 확인한 것입니다. 100%는 이 재실행의 균형 정확도입니다. [011의 시험 구성과 원본 수치](experiment-011.md)

트랙 연결은 모의 환경에서 멈춰 있던 물체를 한 번 미는 경우에 적용됩니다. 010이 학습한 기존 시뮬레이터에서는 도착 이력이 밀기의 결과에 영향을 주지 않습니다. 사람이 작성한 변형 규칙에 이 예외를 추가해 학습하고, 그 가중치가 두 예시의 결과 선택에 미치는 영향을 확인했습니다. 원리 적용 시 경로와 도착 이력의 결합 확률을 보존하고, 움직임 확률은 원리 모델의 점수로 대체합니다. 관찰의 정답은 입력에서 제공하며, 검증 사례 중복 검사는 문장 순서와 공백을 정리한 텍스트 기준입니다. 새로운 표현과 물체에 대해서는 아래 검증이 남아 있습니다.

## 트랙에서 재현하기

고정 다국어 E5를 준비한 뒤 기존 010 관측 모델과 트랙 원리 모델을 학습합니다. [010 관측 모델](experiment-010.md) · [E5 준비](experiment-007.md#재현)

```sh
python -m nascen.theory_language train-robust
python -m nascen.theory_language.principle_study train \
  --domain track-motion --output .nascen/theory-language/track-base.pt
python -m nascen.theory_language.principle_study study \
  --base .nascen/theory-language/track-base.pt \
  --lesson docs/track-motion-principle.json \
  --output .nascen/theory-language/track-student.pt
python -m nascen.theory_language predict \
  --state-facts '물체가 멈춰 있다.' '이동 경로가 열려 있다.' '이미 목표선에 도착한 적이 있다.' \
  --action '실험자가 물체를 세게 밀었다.' \
  --option '물체가 움직이고 있다. 이동 경로가 열려 있다. 이미 목표선에 도착한 적이 있다.' \
           '물체가 멈춰 있다. 이동 경로가 열려 있다. 이미 목표선에 도착한 적이 있다.' \
  --principle-checkpoint .nascen/theory-language/track-student.pt
```

응답의 `baseline_index`는 원리 적용 전 선택인 첫 번째 보기(0)이고, `indices`는 원리 적용 후 선택인 두 번째 보기(1)입니다. 입력과 보기의 도착 이력 문장을 모두 ‘아직 목표선에 도착한 적이 없다.’로 바꾸면 두 모델 모두 첫 번째 보기를 선택합니다.

## 개발 순서

1. **원리를 저장하고 실제 판단에 쓰기.** 현재 구현은 관찰에 따라 원리를 유지하거나 수정하는 단계와, 트랙에서 원리가 다음 상태 선택을 바꾸는 경로까지 확인했습니다.
2. **같은 원리를 새 상황에 적용하기.** 관측 모델과 원리 가중치를 고정한 뒤 학습에 없던 물체, 별도로 작성한 한국어 표현, 조건 조합을 둡니다. 같은 입력에서 원리 적용 전후를 비교하고, 대상 환경의 기준 규칙으로 채점합니다. 예외에서 예측이 개선되는 비율과 평상시 판단이 유지되는 비율을 확인합니다. 문제가 나면 상태·행동 인식과 원리 적용을 따로 검사하고 실패한 부분을 고칩니다.
3. **원리 여럿을 선택하고 조합하기.** 하나의 원리가 재사용되면, 두 원리가 같이 적용되거나 서로 다른 결과를 내는 상황과 여러 단계의 행동을 다룹니다. 어떤 조건에서 어떤 원리가 쓰였는지 검사할 수 있어야 합니다.
4. **설명 없이 관찰에서 원리를 찾기.** 모델이 소수의 관찰에서 후보 원리를 만들고, 다음 결과를 예측하거나 반례를 확인해 후보를 좁힙니다. 그 원리를 고정한 뒤 새 상황에 재사용할 수 있는지 봅니다.
